# ⚔️ Auto Battle Arena (Python, OOP)

Auto Battle Arena — это self-gaming консольная игра на Python

Игра полностью автоматическая: персонажи создаются случайным образом и сражаются друг с другом, пока не останется единственный победитель.

---

## 🎯 Цели проекта

- Закрепить **ООП на практике**, а не на абстрактных примерах
- Научиться **разделять ответственность между классами**


---

## 🧠 Используемые концепции

В проекте осознанно применены:

- Абстрактные классы (`abc.ABC`)
- Наследование
- Композиция (персонаж → оружие)
- `@dataclass`
- Service layer (BattleService, DamageCalculator)
- Factory pattern (CharacterFactory)
- Инкапсуляция
- Управляющий движок (GameEngine)

## ⚔️ Как работает игра

1. Пользователь задаёт количество персонажей
2. Для каждого персонажа случайно:
   - выбирается класс (Knight, Hunter, Magician, Monster)
   - генерируется имя
   - создаётся оружие со случайными параметрами
3. GameEngine запускает цикл игры
4. Персонажи сражаются парами:
   - атаки происходят **поочерёдно**
   - бой продолжается, пока один из бойцов не погибнет
5. Игра завершается, когда остаётся один живой персонаж
